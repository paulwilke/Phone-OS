# Pixel art of the interface symbols, one set per font size (see charset.txt for the code points).
#
# The symbols are our own drawings; they are not part of Lucida and are not covered by its
# licence. Each section is one font and names its capital height (the glyphs of the Lucida
# font it belongs to are that many rows tall); `top` is the number of blank rows between the
# top of the capitals and the top of the symbol, so that a symbol sits on the baseline area
# of its line like a letter does. Rows are drawn with # (black) and . (white), all rows of a
# symbol have the same length, and an empty line ends the symbol.

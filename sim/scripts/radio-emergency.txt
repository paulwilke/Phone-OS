# data: sim/data
# The radio's emergency (D-59, D-62): the radio is off in normal use; the SOS without a mobile network starts it and
# switches save mode on (cellular off); anybody may write during it and is shown, the SOS text is kept off the radio
# (D-61); the one key "End SOS" ends it: the radio stops, cellular is back, and only the radio peer may write again.
advance 5s
check radio no
check emergency-radio no

# A stranger cannot write when the radio runs in normal use: only [radio] peer may.
radio start
advance 2s
radio peer Stranger
radio msg Stranger Hello from the road
advance 1s
check unread 0
check radio yes

# An SOS with a network is the usual one: no emergency of the radio.
key down down select
key select
advance 40s
check sms-sent 1
check emergency-radio no
check cellular on
key back

# An SOS without a network begins the emergency: save mode (cellular off), and the stranger is heard.
network none
advance 5s
key select
key select
advance 2s
check emergency-radio yes
check cellular off
radio msg Stranger Hello from the road
advance 1s
check unread 1

# The text of the SOS waits for the network and is not sent on the radio.
advance 60s
check sms-sent 1
see sos.end

# The child ends the SOS: the radio stops, cellular is back, the stranger is dropped again.
key select
advance 2s
check emergency-radio no
check radio no
check cellular on
network Example Mobile
advance 60s
check sms-sent 2
radio start
advance 2s
radio peer Stranger
radio msg Stranger Are you still there
advance 1s
check unread 1
